  1. Convolution
  • 우리가 아는 cnn에서의 filter를 쓰면 됨
  • 합성곱(Convolution)도 행렬 곱으로 표현할 수 있음!
  • 입력을 펼치면 Toeplitz 구조의 가중치 행렬로 나타낼 수 있음. (2D·다채널에서는 block-Toeplitz 구조)
  • 하지만 일반적인 Fully Connected Layer와 같지는 않음!
  • → 지역성(Locality): 각 출력이 입력의 일부 영역에만 연결됨. (희소 연결)
  • → 가중치 공유(Weight Sharing): 같은 필터를 여러 위치에 반복 적용함.
  • 즉, 합성곱은 지역성과 가중치 공유라는 제약을 가진 Fully Connected Layer의 특수한 형태(부분집합)라고 볼 수 있음.
  • → Convolution은 지역 연결(Local Connectivity) + 가중치 공유(Weight Sharing)를 사용하는 구조!
  • Locally Connected Layer도 주변의 일부 영역에만 연결되지만, 위치마다 서로 다른 가중치를 사용함. (가중치 공유 X)
  • 반면 Convolution Layer는 같은 필터의 가중치를 여러 위치에서 공유함.
  • 즉, 둘 다 지역 연결을 사용하지만 가중치 공유 여부가 핵심 차이!

  • Stride(스트라이드)
  • → Convolution에서 필터를 한 번 이동할 때 몇 칸씩 움직이는지를 나타냄.
  • → Stride = 1이면 필터를 한 칸씩 이동함.
  • → Stride가 커지면 필터가 더 큰 간격으로 이동하므로 출력의 공간 크기가 작아짐. (다운샘플링 효과)
  • 바로 앞 그림의 경우
  • → 입력 크기: 11×11
  • → 필터 크기: 3×3
  • → Stride = 4
  • → Padding = 0 (없음)
  • → 출력 크기: 3×3
  • 출력 크기 공식 (한 축 기준)
  • Output Size = ⌊(Input Size − Filter Size + 2×Padding) / Stride⌋ + 1
  • 그림에 적용하면
  • ⌊(11−3)/4⌋+1 = 3
  • → 가로·세로 각각 3이므로 출력은 3×3!
  • 즉, 이 그림에서는 필터를 가로·세로 방향으로 4칸씩 이동하여 11×11 입력을 3×3 출력으로 줄인 것임.
  • Stride를 크게 하면 출력 크기와 연산량을 줄일 수 있지만, 일부 위치의 정보를 놓칠 수도 있음.

  • Encoder-Decoder Architectures
  • Encoder: 원래 이미지 → 낮은 차원의 Z (다운샘플링)
    Decoder: Z → 이미지 예측 (업샘플링)
  • Decoder의 출력이 반드시 Encoder의 입력과 일치해야 하는 것은 아님!
  • Autoencoder의 경우
  • → Encoder: 입력 x → 잠재 표현 z
  • → Decoder: z → 복원된 입력 x̂
  • → 목표: x̂가 원래 입력 x와 최대한 비슷해지도록 학습함. (입력 재구성)
  • 하지만 일반적인 Encoder–Decoder 구조에서는 입력과 다른 출력을 만드는 것도 가능함!
  • EX
  • → Segmentation: 입력 이미지 → 픽셀별 클래스 예측
  • → Image-to-Image Translation: 입력 이미지 → 변환된 이미지
  • 즉, 입력 재구성은 Autoencoder의 목표이고, Encoder–Decoder 전체에 공통인 목표는 아님!
  • Decoder는 이미지를 만들어 낼 수도 있음

  • ResNet
  • ResNet은 잔차 블록(Residual Block) 단위로 Skip Connection을 사용함.
  • 입력 x를 두 경로로 전달함.
  • → Residual Path: F(x)를 학습함.
  • → Skip Path: 입력 x를 그대로 전달함. (Identity Mapping)
  • 두 경로의 출력을 더함!
  • y = F(x) + x (입출력 차원이 같은 경우)
  • 차원이 다르면 Skip Path에 Projection 등을 적용해 차원을 맞출 수 있음.
  • 이때 처리할지/스킵할지 선택하는 게 아님!
  • → 두 경로는 항상 합산됨. (별도의 게이팅·선택 구조가 아님)
  • 장점
  • → Skip Path를 통해 기울기가 더 잘 전달되어 깊은 네트워크의 학습이 쉬워짐.
  • → F(x)=0에 가까워지면 항등함수 y≈x를 쉽게 표현할 수 있음.
  • 즉, 최적의 깊이를 자동으로 선택하는 구조가 아니라 잔차 학습으로 깊은 네트워크의 최적화를 돕는 구조!
  • 차원 추가
  • Convolution은 기본적으로 평행이동 등변성(Translation Equivariance)을 가짐.
  • → 입력 이미지가 이동하면 출력 특징 맵도 그에 따라 이동함. (stride=1, 경계 효과 등을 제외한 경우)
  • Translation Invariance(평행이동 불변성)와는 다름!
  • → Equivariance: 입력이 이동하면 출력도 대응해서 이동함.
  • → Invariance: 입력이 이동해도 출력이 같게 유지됨.
  • Pooling 등을 사용하면 작은 위치 변화에 대해 근사적인 불변성을 얻을 수 있음. (항상 보장되는 것은 아님)
  • 주의할 점!
  • → Stride나 Pooling으로 다운샘플링할 때 Aliasing이 발생할 수 있음.
  • → 이 때문에 작은 위치 이동에도 출력이 달라져 등변성이나 기대한 불변성이 깨질 수 있음.
  • 위치 정보를 명시적으로 사용하고 싶다면?
  • 1. MLP 사용
  • → 일반적인 MLP는 평행이동 불변성이나 등변성을 구조적으로 강제하지 않음.
  • → 대신 CNN의 지역성·가중치 공유라는 귀납적 편향도 포기하는 선택임.
  • 2. Positional Encoding 사용
  • → 입력 특징에 위치 정보를 추가하여 모델이 위치를 구분할 수 있게 함.
  • → 위치 인코딩은 학습 가능한 형태(Learned)도 있고, 고정된 형태(Fixed)도 있음.
  • → Sinusoidal Positional Encoding은 학습하지 않는 고정형의 대표적인 예!
  • 즉, Positional Encoding은 위치를 반드시 추가로 학습하는 방식이 아니라, 위치 정보를 모델에 제공하는 장치임.

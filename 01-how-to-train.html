Stochastic Gradient Descent(SGD)
  • 데이터가 너무 많아서, 학습하기 힘들 때가 많음
  • 전체 데이터 대신 일부 데이터를 무작위로 뽑아서 gradient를 계산함.
  • 엄밀한 SGD → 샘플 1개로 gradient 계산
  • Mini-batch GD → 여러 샘플로 이루어진 작은 batch로 gradient 계산
  • 전체 데이터 N개에 대한 평균 손실이 L(θ) = (1/N) Σᵢ₌₁ᴺ ℓᵢ(θ) 이면,
  • 전체 gradient: g = (1/N) Σᵢ₌₁ᴺ ∇ℓᵢ(θ)
  • Mini-batch gradient: gB = (1/|B|) Σᵢ∈B ∇ℓᵢ(θ)
  • 무작위로 균등 추출하면 → E[gB] = g
  • 즉, mini-batch gradient는 전체 gradient의 불편추정량(unbiased estimator)임.
  • 매번 똑같거나 비슷하다고 가정하는 게 아니라, 기댓값이 같다는 뜻임.
  • 일부 데이터만 계산하므로 한 번의 업데이트 비용이 작음.
  • 하지만 sampling에 따른 분산이 있어서 → 업데이트 방향이 흔들리고 학습이 불안정할 수 있음.
  • 이렇게 하면 빠름. + 로컬 minimum에서 벗어날 수 있음
    좀 불안정함.
Momentum

  • 너무 작은 모멘텀 → 최소값에 적당히 천천히 감

Evolution Strategies
Gradient clipping
  • 기울기가 너무 커지면 → 기울기 자체를 제한함.
  • 매개변수 변화량이 아니라 gradient가 1차적인 clipping 대상임.
  • g = ∇L(θ), c > 0 (clipping threshold)
  • Norm clipping
  • ||g|| > c이면 전체 gradient를 재조정함.
  • gclip = g · min(1, c/||g||)
  • → gradient의 norm을 최대 c로 제한함.
  • → 원래 gradient의 방향은 유지됨.
  • Value clipping
  • 각 gradient 성분을 [-c, c] 범위로 제한함.
  • (gclip)ᵢ = max(-c, min(c, gᵢ))
  • → 각 성분을 개별적으로 잘라냄.
  • → 전체 gradient의 방향은 바뀔 수 있음.
  • Clipping한 gradient로 매개변수를 업데이트함.
  • θ ← θ − ηgclip
  • 즉, 너무 큰 gradient 때문에 업데이트가 과도해지는 것을 방지하는 방법임.
Loss function
  • 손실 함수를 최소화하기 위해 gradient를 계산함.
  • 전 구간에서 미분 가능하거나 smooth할 필요는 없음.
  • 대부분의 점에서 미분 가능하면 gradient 기반 학습이 가능하고, 미분 불가능한 점에서도 부분기울기(subgradient)가 정의되면 이를 이용할 수 있음.
  • EX> ReLU = max(0, z)
  • ReLU는 손실 함수가 아니라 활성화 함수(activation function)임.
  • z = 0에서 미분 불가능하지만, 해당 지점에서 사용할 기울기 값을 정해 학습할 수 있음.
  • GELU는 smooth한 활성화 함수임.
  • ReLU 대신 GELU를 쓰기도 하지만, 선택 이유가 smooth함 하나만은 아님.

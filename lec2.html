Perceptron

  • ※ 캡처 1의 입력 표기에서 두 번째 X₁은 오기이며, X₂로 표기하는 것이 맞음.
  • Perceptron은 입력의 가중합 w·x를 임계값 θ와 비교하여, w·x > θ이면 활성화되는 구조임. 여기서 θ는 가중합과 비교되는 기준값이며, bias 자체를 넘는다는 의미는 아님. bias를 사용하는 표현에서는 w·x + b > 0 ⟺ w·x > −b이므로 θ = −b의 관계가 성립함. 캡처 1의 w·x ≥ T라는 표기도 b = −T로 두면 w·x + b ≥ 0으로 동일하게 표현할 수 있음. 단, >와 ≥는 임계값에서의 포함 여부가 다르므로 각각 구분해야 함.

Logistic

  • Perceptron에서 사용하는 step 함수도 activation function(활성화함수)의 일종이며, sigmoid 함수 역시 활성화함수의 한 예임. 입력의 가중합과 bias를 z = w·x + b로 두면, sigmoid 활성화함수를 사용한 출력은 y = σ(z) = 1/(1 + e−z)로 표현됨. Step 함수는 임계값을 기준으로 출력이 불연속적으로 바뀌지만, sigmoid 함수는 연속적인 값을 출력하므로 perceptron의 출력을 보다 soft하게 만들 수 있음. 즉, 활성화함수라는 용어는 sigmoid에만 해당하는 것이 아니라 step 함수 등에도 적용됨.

  • Edge에는 weight(W)가 부여되고, node에서는 입력의 가중합을 임계값 θ와 비교함. θ는 활성화 여부를 결정하는 기준값이며, bias와는 θ = −b의 관계가 있음. Weight와 bias(또는 임계값 θ)를 적절히 설정하면 AND / OR / NOR 등의 Boolean 함수를 표현할 수 있음. 다만 단일 perceptron이 모든 Boolean 함수를 표현할 수 있는 것은 아니며, 선형적으로 분리할 수 없는 Boolean 함수는 단일 perceptron만으로 표현할 수 없음.

MLP as a classifier

  • perceptron은 아래와 같은 hyperplane으로 볼 수 있다.
  • 경계를 넘으면 → 1이고, 넘지 않으면 0으로 표현됨.
  • 오른쪽과 같이 2개의 경계가 필요한 경우(XOR)에는, single perceptron으로 나타낼 수 없다.
  • 각 perceptron이 경계 1개를 만듦 → 5개면 5개의 경계를 만들 수 있음.
    → decision boundaries
  • 이를 2개 겹치면 → 2개의 boundaries를 나타낼 수 있음.
    → 이를 통해서 더욱 복잡한 boundaries를 구성할 수 있는 것
  • 뉴런의 합이 사실 주변값이랑 큰 차이가 안 남.
  • size를 늘리면(도형 변이 늘어남) → 이걸 해결할 수 있음.(원모양)
    안은 n
    밖은 n/2 값으로 수렴하게 됨.
  • UAT(Universal Approximation Theorem)에 따르면, 콤팩트 집합 K 위의 임의의 연속함수 f에 대해, 연속인 비다항식 활성화함수를 사용하는 one-hidden-layer MLP는 충분한 수의 hidden unit을 사용하여 임의의 ε > 0에 대해 ∥f − f̂∥∞ < ε를 만족하는 근사 함수 f̂를 존재하게 할 수 있음. 이는 모든 classification 문제를 반드시 '해결'한다는 의미가 아니라 함수 근사가 가능하다는 존재 정리임. 또한 이러한 근사를 실현하는 가중치를 실제 학습 과정에서 반드시 찾을 수 있다는 보장은 없으며, 결정 경계 근처에서는 작은 근사 오차로도 오분류가 발생할 수 있음.
  • hidden-layer를 늘리면, 이런 분류를 더욱 효율적으로 할 수도 있음.

Optimal depth

  • 이런 복잡한 경계를 one-hidden-layer로 나타내려면 점으로 다 찍어야 함.
  • 근데, 퍼셉트론을 2층으로 쌓으면 → 이런 경계를 더 쉽게 나타낼 수 있음.
  • 이 경우에는 XOR을 계속 쌓으면 됨.! → 적은 노드로 해결 가능

Perceptron(퍼셉트론)

  • w\*x 의 sum이 임계값을 넘으면, 활성화되는 하나의 함수이다.
    → bias를 넘는 것이라고 생각할 수 있을듯.

Logistic

  • y함수를 위와 같이 둠으로서, perceptron을 soft하게 만들 수 있다.
  • ⇒ 이런 함수를 activation function(활성화 함수)이라고 한다.
  • affine combination(아핀 결합)
    - 3x + 7y + 4처럼 + constant가 있는 linear combination 형태

multi-layer perceptron(다층 퍼셉트론) / Depth

  • mlp는 depth가 있는 network라고 할 수 있다.
depth는 무엇일까?
input(source node) - output까지 path에서 지나는 노드의 개수
  • Layer의 정의는?
    set of node - that has same depth
  • Mlp는 boolean functions이 될 수 있음.
  • edge = W, node value = 임계점.
    → node value와 weight를 통해서 and / or / nor 등등 모든 boolean을 나타낼 수 있음
  • 어떤 boolean function(부울 함수)이든 하나의 hidden layer(은닉층)로 표현할 수 있음.
    진리표 하나로 표현할 수 있듯이, 한층이면 Truth Table을 모두 표현할 수 있음.

MLP as a classifier

  • perceptron은 아래와 같은 hyperplane(초평면)으로 볼 수 있다.
  • 경계를 넘으면 → 1이고, 넘지 않음녀 0으로 표현됨.
  • 오른쪽과 같이 2개의 경계가 필요한 경우(XOR)에는, single perceptron으로 나타낼 수 없다.
  • 각 perceptron이 경계 1개를 만듦 → 5개면 5개면을 만들 수 있음.
    → decision boundaries
  • 이를 2개 겹치면 → 2개의 boundaries를 나타낼 수 있음.
    → 이를 통해서 더욱 복잡한 boundaries를 구성할 수 있는 것
  • 뉴런의 합이 사실 주변값이랑 큰 차이가 안 남.
  • size를 늘리면(도형 변이 늘어남) → 이걸 해결할 수 있음.(원모양)
    안은 n
    밖은 n/2 값으로 수렴하게 됨.
  • 이런 원들을 합치면 → 어떤 분류 문제도 해결할 수 있음.
    즉, one-hidden-layer MLP도 classification문제를 해결할 수 있음!
  • hidden-layer를 늘리면, 이런 분류를 더욱 효율적으로 할 수도 있음.

Optimal depth

  • 이런 걸, one-layer로 나타내려면 다 점으로 찍어야 함.
  • 근데, 퍼셉트론을 2층으로 쌓으면 → 이런 경계를 더 쉽게 나타낼 수 있음.
  • 이 경우에는 XOR을 계속 쌓으면 됨.! → 적은 노드로 해결 가능

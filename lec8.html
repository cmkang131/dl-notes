Lec8. Training Part VI

Generalization / Tricks of the trade

Training Neural Nets by Gradient Descent

  • 신경망 학습에서는 출력과 목표값의 특성에 따라 L2 loss(제곱오차), cross-entropy, KL divergence 등을 선택할 수 있다.
  • 이진분류에서 y ∈ (0,1), d ∈ [0,1]이면 binary cross-entropy는 LCE = −d·log y − (1−d)·log(1−y)이다.
  • Binary KL divergence는 DKL(d∥y) = d·log(d/y) + (1−d)·log((1−d)/(1−y))이며, 0 log 0 = 0으로 정의한다.
  • 두 함수는 d에만 의존하는 상수항만 다르므로 목표값을 고정하고 y를 최적화할 때 gradient가 같다.
  • 특히 d ∈ {0,1}이면 두 식의 값도 일치한다.
  • Cross-entropy 또는 DKL(d∥y)는 softmax logits에 대해 볼록하며, 입력 특징이 고정된 선형 분류기의 마지막 층 가중치에 대해서도 볼록하다.
  • 반면 sigmoid 출력에 제곱오차를 적용하면 logits에 대한 손실조차 비볼록할 수 있다.
  • 그러나 다층 신경망에서는 logits가 가중치의 비선형 함수이므로, cross-entropy나 KL divergence를 사용하더라도 전체 가중치에 대한 손실함수가 일반적으로 볼록한 것은 아니다.
  • 따라서 손실함수의 종류뿐 아니라 출력 activation과 모델 구조를 함께 고려해야 한다.
  • 출력 activation은 손실함수와 합성되어 loss surface의 형태와 gradient에 영향을 준다.
  • 예를 들어 y = σ(z) 또는 y = softmax(z)이고 z = fW(x)라면, 파라미터 W에 대한 loss surface는 L(W) = ℓ(y(fW(x)), d)로 결정된다.
  • 따라서 activation만으로 loss surface를 판단할 수 없으며, 출력 activation과 손실함수의 조합, 그리고 네트워크 구조를 함께 분석해야 한다.

A note on derivatives

  • Backpropagation에서 필요한 것은 손실함수를 출력 이전의 logit z에 대해 미분한 값이다.
  • 선형 출력 y = z와 L2 loss L = (1/2)∥y−d∥2를 결합하면 ∇z L = y−d이다.
  • 또한 softmax 출력 y = softmax(z)와 cross-entropy 또는 DKL(d∥y)를 결합하면 ∇z L = y−d가 된다.
  • 그러나 sigmoid 출력과 L2 loss를 결합하면 ∂L/∂z = (y−d)y(1−y)이므로 일반적으로 같지 않다.
  • 따라서 도함수가 y−d로 단순화되는 것은 특정 activation–loss 조합의 성질이며, L2와 KL의 학습 과정이 일반적으로 동일하다는 의미는 아니다.

The problem of covariate shifts

  • 일반적인 covariate shift는 입력 데이터의 분포 P(X)가 달라지는 현상이며, internal covariate shift는 학습 중 앞쪽 층의 가중치가 갱신되면서 뒤쪽 층이 받는 activation의 분포가 변하는 현상을 가리키는 용어다.
  • Mini-batch마다 표본평균과 표본분산이 다른 것은 표본 추출에 따른 변동일 수도 있으므로 두 개념을 동일시해서는 안 된다.
  • Batch Normalization은 각 mini-batch의 activation을 정규화하여 학습을 안정화하는 방법이며, 그 효과는 단순한 분포 변화 억제뿐 아니라 gradient와 최적화 지형의 성질과도 관련된다.
  • Batch Normalization은 mini-batch의 각 특징에 대해 평균을 빼서 중심을 0으로 옮기고, √(σB2+ϵ)으로 나누어 분산의 크기를 정규화한다.

    σ : Minibatch standard deviation
  • 이어서 학습 가능한 γ와 β를 사용해 출력을 affine 변환한다.
  • 이 과정은 mini-batch 간 평균과 분산의 차이를 줄일 수 있지만 분포의 모든 형태를 동일하게 만드는 것은 아니며, 정규화 직후의 분산도 일반적으로 σB2/(σB2+ϵ)이다.
  • ⇒ “Move all minibatch to a “standard” location” 부분이랑 같은 것을 하는 거임.(위에)

Batch Normalization : Scale & Shift

  • ẑᵢ = γuᵢ + β
    • γ (Gamma) : Scale → 분포의 크기 조절
      β (Beta) : Shift → 분포의 위치 이동
    • Batch Normalization은 ui = (zi − μB)/√(σB2+ϵ)으로 정규화한 뒤 ẑi = γui + β를 적용한다.
    • 정규화된 u의 평균은 0이고 분산은 σB2/(σB2+ϵ)이다.
    • Scale 파라미터 γ와 shift 파라미터 β를 적용하면 ẑ의 평균은 β, 분산은 γ2σB2/(σB2+ϵ)가 된다.
    • 따라서 γ, β는 정규화된 활성값의 크기와 위치를 학습 가능한 방식으로 조절하며, 모델이 표현에 필요한 scale과 shift를 선택하도록 한다.
  • ⇒ Batch Normalization = 정규화 + Scale & Shift

Batch Normalization : Gradient 계산

1. Without BN

  • Loss = (1/B) Σᵢ Lᵢ
    ∇Loss = (1/B) Σᵢ ∇Lᵢ
    • BN처럼 batch 내 샘플을 결합하는 연산이 없고, 각 샘플의 순전파가 독립적이며, 전체 손실이 L = (1/B) Σi Li로 분리되는 경우 각 Li와 개별 gradient ∇θ Li는 고정된 파라미터 θ 아래에서 다른 샘플의 입력값에 의존하지 않는다.
    • 이 경우 ∇θ L = (1/B) Σi ∇θ Li가 된다.
    • 그러나 BN이나 샘플 간 비교를 사용하는 손실함수가 있다면 개별 출력 또는 손실이 다른 샘플에 의존할 수 있다.

2. With BN(BatchNorm)

  • 완전연결층의 Batch Normalization에서는 각 특징 차원마다 mini-batch에 속한 B개 값 z1, …, zB에 대해 μB = (1/B) Σi=1B zi, σB2 = (1/B) Σi=1B (zi − μB)2를 계산하고, ui = (zi − μB)/√(σB2+ϵ)으로 정규화한다.
  • 여기서 B ≥ 1, ϵ > 0이다.
  • CNN에서 일반적으로 사용하는 공간적 BN은 채널별로 batch 및 공간 위치에 걸쳐 평균과 분산을 계산한다.
  • → 가 모든 데이터에 의해 결정됨.
  • → 각 데이터의 출력과 Loss가 Batch 내 다른 데이터에도 의존하게 됨.
  • → Backpropagation 시 다른 데이터의 영향까지 고려해야 함.
  • ⇒ BN은 Mini-batch 내 데이터 간 의존성을 만들어 Gradient 계산을 복잡하게 함.
  • BN의 affine 변환은 ẑi = γui + β이며, γ, β는 같은 특징 차원의 모든 mini-batch 샘플이 공유한다.
  • 전체 batch 손실을 L, 상류 gradient를 δi = ∂L/∂ẑi라고 두면 ∂L/∂γ = Σi=1B δi ui, ∂L/∂β = Σi=1B δi이다.
  • 각 샘플에서 얻은 국소 미분 기여분은 공유 파라미터에 대해 모두 합산해야 하며, δi에 손실 평균의 1/B가 이미 포함되어 있다면 추가로 나누지 않는다.

Batchnorm is a vector function over the minibatch

  • Batch Normalization 는 vector function과 다를 게 없음.
    • → 왜냐하면, 모든 가 에 영향을 주게 됨
  • 각 에 대해서, , 모두 바뀌며, 이에 의해 가 바뀜.
  • 따라서, 이와 같이 가 되게 됨.
  • 각 미분결과를 넣으면 → 위와 같은 방정식을 구할 수 있음.
  • BN의 Jacobian 유도: ui = (zi − μB)/s, s = √(σB2 + ϵ)라고 두자.
  • 모든 zj는 μB와 σB2에 영향을 주므로 ui는 자신의 입력뿐 아니라 batch의 다른 입력에도 의존한다.
  • 먼저 ∂μB/∂zj = 1/B, ∂σB2/∂zj = 2(zj − μB)/B를 구한다.
  • 다음으로 chain rule을 적용하면 ∂ui/∂zj = (δij − 1/B)/s − (zi − μB)(zj − μB)/(B·s3)을 얻는다.
  • 여기서 δij = 1은 i = j일 때이고, 그렇지 않으면 0이다.
  • 핵심: i = j에서는 직접 미분 경로가 추가되지만, i ≠ j에서도 평균과 분산을 통한 간접 미분 경로가 존재한다.
  • 따라서 BN의 Jacobian은 일반적으로 대각행렬이 아니며, Backpropagation에서는 다른 샘플에서 전달되는 gradient도 합산해야 한다.

Batch normalization : Inference

Training

  • 현재 Minibatch의 평균 , 분산 사용.
    Minibatch가 바뀌면 정규화 기준도 달라짐.

Inference

  • Batch Normalization은 Training에서 현재 mini-batch의 평균 μB와 분산 σB2를 사용하지만, 일반적인 Inference에서는 학습 중 추정해 저장한 running mean μrun과 running variance σrun2를 고정하여 사용한다.
  • 따라서 추론식은 ẑi = γ(zi − μrun)/√(σrun2+ϵ) + β이다.
  • Running 통계량은 구현에 따라 이동평균이나 별도 집계 방식으로 추정할 수 있다.
  • 동일한 크기 B > 1의 mini-batch를 동일한 모집단에서 독립적으로 표본 추출했다면 B/(B−1)을 이용한 batch 분산의 불편추정이 가능하지만, 이렇게 평균한 값이 임의로 구성된 전체 데이터의 정확한 분산과 항상 일치하는 것은 아니다.
  • Inference에서는 정규화 통계량과 학습된 γ, β를 고정하므로 개별 샘플을 다른 추론 샘플과 독립적으로 처리할 수 있다.
  • ⇒ Training에서는 Minibatch별 통계량을 사용하지만, Inference에서는 학습 중 저장한 통계량을 고정해서 사용함.
  • ⇒ 따라서 Inference에서는 다른 데이터에 의존하지 않고 개별 데이터를 예측할 수 있음.

Batch Normalization : Application & Benefits

1. 적용 위치

  • 일반적으로 Wx + b → BN → Activation 순서
    모든 Layer에 적용할 필요는 없음

2. 효과

  • Faster Convergence : 학습 안정화 → 더 큰 Learning Rate 사용 가능
    Better Generalization : Regularization 효과로 성능 개선 가능
    Less Dropout : BN이 일부 Regularization 역할 수행
    그러나 learning rate decay의 적절한 속도는 BN 사용 여부만으로 결정되지 않으며, optimizer와 검증 성능에 따라 조정해야 한다.
    일반적인 무작위 표본 기반 학습에서는 데이터를 shuffle하여 mini-batch 간 구성 편향을 줄이는 것이 도움이 될 수 있지만, 순서 정보가 중요한 학습에서는 데이터의 시간적·구조적 제약을 고려해야 한다.
  • Batch Normalization은 gradient의 안정성을 높여 더 큰 learning rate를 사용할 수 있게 하거나 학습 수렴을 빠르게 만드는 경우가 있다.
  • BN의 수렴 및 일반화 효과 역시 모델과 학습 조건에 따라 달라진다.
  • Optimization 효과: Batch Normalization은 학습을 더 안정적으로 만들고 경우에 따라 더 큰 learning rate를 허용하여 수렴 속도를 향상시킨다. 다만 모든 모델에서 수렴이 빨라지는 것은 아니다.
  • Regularization 및 Generalization 효과: Training 과정에서 mini-batch 통계량이 달라지는 것은 일부 정규화 효과를 제공할 수 있으며, 이에 따라 일반화 성능이 향상되거나 다른 정규화 기법의 필요성이 감소하는 경우가 있다.
  • 학습 설정 시 고려사항: Learning rate schedule은 검증 성능에 맞추어 조정해야 한다. Mini-batch 구성은 BN 통계량에 영향을 주므로, 일반적인 무작위 표본 기반 학습에서는 적절한 shuffling이 도움이 될 수 있다. Batch size가 너무 작으면 통계량 추정의 변동성이 커질 수 있으므로 batch 크기도 고려해야 한다.
  • ⇒ BN은 학습을 안정화하고 수렴 속도와 일반화 성능을 개선하는 데 도움을 줌.

Overfitting and Smoothing

  • 정답: 파란색 함수
    이 상황에서, 보라색으로 학습되는 것을 막기 힘듦.
  • 방지하려면? → 왜 이게 학습되는지를 봐야 함.
  • 일부 신경망에서는 가중치의 크기가 커질수록 출력 함수가 더 급격하게 변하거나 학습 데이터에 지나치게 민감한 함수를 표현할 수 있다.
  • 예를 들어 sigmoid σ(wx)의 전이 구간은 |w|가 커질수록 가파르게 변한다.
  • L2 정규화는 손실함수에 (λ/2) Σk ∥Wk∥F2를 추가하여 큰 가중치에 불이익을 주는 방법이다.
  • 이를 통해 함수의 복잡성이나 극단적인 가중치 증가를 억제하고 과적합을 완화할 수 있지만, 모든 종류의 과적합을 반드시 방지하는 것은 아니다.
  • = 정규화항을 두면 됨.
  • L2 정규화가 없는 SGD의 파라미터 갱신은 Wk ← Wk − ηgk이다.
  • 손실함수에 (λ/2)∥Wk∥F2를 추가하면 ∇Wₖ L = gk + λWk가 되므로 Wk ← Wk − η(gk + λWk) = (1−ηλ)Wk − ηgk로 갱신된다.
  • β = ηλ로 두면 Wk ← (1−β)Wk − ηgk이며, 정규화가 없을 때 Wk 앞의 계수는 1이다.
  • 이처럼 L2 정규화가 추가된 SGD에서는 매 단계 가중치를 줄이는 weight decay 효과가 나타난다.
  • 신경망의 깊이가 증가하면 여러 비선형 변환을 합성할 수 있으므로 특정한 복잡한 함수를 상대적으로 적은 뉴런 또는 파라미터로 효율적으로 표현할 수 있다.
  • 따라서 같은 정도의 모델 자원을 사용하더라도 더 깊은 구조가 유리한 함수와 데이터가 존재한다.
  • 그러나 깊이가 증가한다고 학습 정확도나 일반화 성능이 항상 향상되는 것은 아니며, 최적화의 어려움과 데이터 특성을 함께 고려해야 한다.
Dropout : 학습하면서, 뉴런을 일부러 비활성화 함.
  • training을 하면서,
  • Dropout은 Training 과정에서 미리 설정한 유지 확률 p에 따라 뉴런의 출력을 무작위로 0으로 만드는 정규화 기법이다.
  • 어떤 뉴런이 중요한지 판단해 선택적으로 제거하는 것은 아니며, 비활성화된 뉴런에 연결된 경로가 해당 학습 단계에서 기여하지 않도록 한다.
  • 매 학습 단계마다 서로 다른 부분 네트워크가 활성화되고 이들이 파라미터를 공유하면서 학습하므로 특정 뉴런 간의 과도한 공동 적응을 줄일 수 있다.
  • 일반적인 Dropout은 네트워크 구조 자체를 영구적으로 학습하거나 변경하는 기법이 아니다.
일반적인 신경망에서는 일부 뉴런이 다른 특정 뉴런의 출력에 과도하게 의존하는 공동 적응(co-adaptation)이 발생할 수 있다.
  • Dropout은 학습 중 뉴런의 출력을 무작위로 제거하여 특정 뉴런 조합에만 의존하는 것을 어렵게 만들고, 다양한 부분 네트워크에서도 유용한 표현을 학습하도록 유도한다.
  • 이를 통해 과적합을 완화할 수 있지만, 모든 feature 중복을 제거하거나 공동 적응을 완전히 방지하는 것은 아니다.

Training

  • 뉴런을 무작위로 비활성화
    → N개 뉴런에 대해 최대 개의 Sub-network를 학습하는 효과

Inference

  • Dropout은 학습 중 무작위 mask에 의해 생성되는 여러 부분 네트워크가 파라미터를 공유하도록 학습하며, 추론 시에는 이들의 예측 결합 효과를 하나의 네트워크로 효율적으로 근사한다.
  • 비선형 함수에서는 일반적으로 E[f(Y)] ≠ f(E[Y])이므로, 뉴런 출력의 기대값을 사용하는 스케일링 방식이 모든 부분 네트워크의 예측 평균을 정확히 계산하는 것은 아니다.
  • 특히 단일 네트워크의 출력이 부분 네트워크 예측의 산술평균과 항상 일치하지 않으며, 원래 Dropout의 모델 결합 해석에는 확률 예측의 정규화된 기하평균에 대한 근사도 포함된다.
  • 따라서 Dropout의 inference scaling은 일반적으로 정확한 앙상블 평균이 아니라 효율적인 근사 방법으로 이해해야 한다.

실제 구현

  • 유지 확률을 p, Dropout mask를 D ∼ Bernoulli(p), Dropout 적용 전 활성값을 a라고 하자.
  • Standard Dropout은 Training에서 atrain = Da를 사용하고 Inference에서는 atest = pa를 사용한다.
  • 이는 다음 층의 해당 활성값에 연결되는 가중치를 p배 하는 것과 동등하게 구현할 수 있지만, 모든 가중치와 bias를 일괄적으로 스케일링한다는 의미는 아니다.
  • Inverted Dropout은 0 < p ≤ 1에서 Training 중 atrain = Da/p로 보정하고 Inference에서는 atest = a를 사용한다.
  • 두 방식 모두 학습·추론 단계에서 해당 활성값의 기대 크기를 일치시키는 것이 목적이며, 전체 비선형 네트워크의 예측 기댓값까지 정확히 보존한다는 의미는 아니다.
  • ⇒ Dropout은 여러 Sub-network의 Ensemble 효과를 하나의 네트워크로 근사하는 방법임.
    • 1. Dropout의 정의: Dropout은 학습 중 유지 확률 p에 따라 각 뉴런의 출력을 무작위로 0으로 만들어 공동 적응을 완화하는 정규화 기법이다.
    • 2. Training: D ∼ Bernoulli(p)를 사용하여 각 뉴런의 출력에 mask를 적용한다. Standard Dropout은 atrain = Da이며, Inverted Dropout은 atrain = Da/p이다.
    • 3. Inference: Standard Dropout에서는 atest = pa로 출력 크기를 보정한다. Inverted Dropout에서는 학습 시 미리 보정했으므로 atest = a를 사용한다.
    • 4. 기댓값: Standard Dropout은 E[Da] = pa, Inverted Dropout은 E[Da/p] = a를 만족한다. 이 등식은 Dropout이 적용되는 개별 활성값에 대한 기대값 관계다.
    • 5. Ensemble 해석: 매번 다른 mask가 만들어내는 부분 네트워크는 파라미터를 공유하며 학습된다. 추론 시에는 하나의 전체 네트워크를 사용하여 이들의 예측 결합 효과를 근사한다. 일반적인 비선형 신경망에서 단일 네트워크의 출력이 모든 부분 네트워크 예측의 정확한 평균과 같다는 보장은 없다.

2 attention
  • 원래 토큰이 학습되는 방식
  • Attention에서 A(attention weight matrix) 자체는 독립적으로 학습되는 자유 파라미터(free parameter)가 아니라, 입력 데이터에 따라 동적으로 계산되는 값이다.
  • 구체적으로 query와 key로부터 attention score를 계산하고, softmax를 적용하여 A를 얻는다. 따라서 입력이 달라지면 A도 달라진다.
  • 그러나 attention 메커니즘 전체에 학습 파라미터가 없는 것은 아니다. Query, key, value를 생성하는 projection 행렬 Wq, Wk, Wv와 최종 output projection 행렬 Wo는 학습 가능한 파라미터이다.
  • 즉, A는 입력으로부터 계산되는 attention weight이고, Wq, Wk, Wv, Wo는 학습 과정에서 업데이트되는 파라미터이다.
  • 직관적으로
    ex1) How many animals are in the photo?
    attend → animals의 head.
    ex2) What is the color of the impala?
    attend → impala
  • 이런 식으로 중요한 정보에 attend해야 한다.
query-key-value attention
  • question → attention을 판단함.
  • Query :
    Key :
  • (이미지라면) 각 patch들이 key를 가지고 있고,
    이곳에다가 query를 곱함으로서(유사성을 확인해봄)
    → 이게 attend할만한 것인지를 판단하는 거임
  • 이런 내적값(s : 유사율)이 됨.
  • Value :
  • Attention은 query와 key 사이의 유사도를 계산하여 각 value에 부여할 가중치를 구하는 방식이다.
  • Scaled dot-product attention에서는 query Q와 key K의 내적을 이용하여 attention score s를 계산한다.
  • s = QKᵀ / √dk
  • A = softmax(s) = softmax(QKᵀ / √dk)
  • 여기서 dk는 key 벡터의 차원이다. 내적의 크기는 차원이 커질수록 커질 수 있으므로 √dk로 나누어 score의 크기를 조정한다. 이 scaling이 없으면 큰 내적값으로 인해 softmax가 포화되어 기울기가 매우 작아질 수 있다.
  • Softmax는 각 query에 해당하는 행(row)마다 key 방향으로 적용되며, 각 행의 attention weight 합은 1이 된다.
  • 이렇게 계산된 attention weight A를 value V에 곱하여 출력값을 얻는다.
  • output = AV
  • 따라서 A는 query와 key의 유사도로부터 계산된 가중치 행렬이며, 실제 attention 출력은 이 가중치를 value에 적용한 결과이다.
  • A(attention) · value →
  • Attention에서는 attention weight matrix A를 value matrix V에 곱하여 출력을 계산한다.
  • 올바른 행렬 곱 순서는 A·V이며, V·A가 아니다.
  • Self-attention에서 토큰 수가 N이고 value 벡터의 차원이 dv이면 각 행렬의 크기는 다음과 같다.
  • • A: N×N
  • • V: N×dv
  • • AV: N×dv
  • 따라서 attention의 출력은 다음과 같다.
  • Tout = A Vin
  • 여기서 A는 각 query 토큰이 key 토큰들에 부여하는 attention weight이고, Vin은 입력 value matrix이다.
  • A와 Vin을 곱하면 각 query 위치에서 value 벡터들의 가중합이 계산되며, 결과 Tout의 크기는 N×dv가 된다.
  • 즉, attention 출력은 value에 attention을 뒤에서 곱하는 것이 아니라, attention weight A를 왼쪽에서 value V에 곱하여 계산한다.

Attention mathematics
  • Self-attention에서는 동일한 입력 시퀀스 T로부터 query, key, value를 각각 선형 투영(linear projection)하여 생성한다.
  • Q = T Wq
  • K = T Wk
  • V = T Wv
  • 여기서 Wq, Wk, Wv는 학습 가능한 projection 행렬이다.
  • 입력 시퀀스의 토큰 수가 N이면, Q와 K를 곱하여 N×N 크기의 attention score matrix를 계산한다.
  • s = QKᵀ / √dk
  • A = softmax(QKᵀ / √dk)
  • A의 크기는 N×N이며, 각 행은 하나의 query 토큰이 전체 key 토큰에 부여하는 attention weight를 나타낸다. Softmax는 각 query 행에서 key 방향으로 적용된다.
  • 계산된 A를 V에 곱하면 self-attention의 출력이 된다.
  • output = AV
  • 즉, self-attention은 동일한 입력으로부터 Q, K, V를 생성하고, 각 토큰 사이의 관계를 나타내는 N×N attention matrix를 계산한 다음 이를 value에 적용하는 방식이다.

why not remember everything?
  • time 차이가 큰 곳의 결과에 영향을 주려면, 많은 W를 거쳐야 함.
  • 항을 가지게 됨.
  • RNN에서는 시간 단계를 거치며 recurrent weight가 반복적으로 적용되므로, 역전파 과정에서 기울기 소실(vanishing gradient) 또는 기울기 폭발(exploding gradient)이 발생할 수 있다.
  • 스칼라 W를 반복해서 곱한다고 가정하면, |W| < 1일 때 값이 0으로 수렴하고 |W| > 1일 때 값이 커질 수 있다. 그러나 이는 현상을 설명하기 위한 단순한 스칼라 직관이며, 실제 RNN의 행렬 연산에 그대로 적용할 수는 없다.
  • 행렬 W의 반복적인 효과는 스펙트럼 반경(spectral radius)과 노름(norm) 등을 고려하여 분석해야 한다. 특히 실제 BPTT(Backpropagation Through Time)의 기울기 전파는 recurrent weight만이 아니라 활성화 함수의 도함수까지 포함한 야코비안(Jacobian)의 곱에 의해 결정된다.
  • Jt = diag(φ′(at))W
  • 여기서 at는 시간 t의 활성화 함수 입력이고, φ′는 활성화 함수의 도함수이다. 여러 시간 단계에 걸친 기울기는 Jt, Jt−1, … 등의 연속적인 곱에 영향을 받으며, 그 크기가 지나치게 작아지거나 커질 수 있다.
  • 따라서 단순히 W를 1에 가깝게 만드는 것만으로 기울기 문제를 해결할 수는 없다. 이러한 장기 의존성 학습의 어려움을 완화하기 위해 cell state와 gating mechanism을 사용하는 LSTM이 도입되었다.
  • ⇒ LSTM을 사용하기 시작함.

Sequence models
  • Autoregressive models.
  • → 다음 단어를 예측하는 방식.
  • Sequence model의 언어 모델 학습 방식에는 다음 토큰 예측(next-token prediction)과 마스킹된 토큰 예측(masked language modeling) 등이 있다. 두 방식은 서로 구분해야 한다.
  • GPT류의 autoregressive language model은 이전 토큰들을 조건으로 다음 토큰을 예측하는 방식으로 학습한다. 각 위치에서 왼쪽 문맥만 참조하며, 미래 토큰을 직접 참조하지 않도록 causal masking을 적용한다.
  • 반면 BERT류의 masked language model은 입력 시퀀스의 일부 토큰을 마스킹하고, 주변 문맥을 이용하여 해당 토큰을 예측하는 방식으로 학습한다. 이때 마스킹된 위치의 왼쪽과 오른쪽 문맥을 모두 활용할 수 있다.
  • 따라서 다음 토큰 예측은 autoregressive 학습 방식이고, 빈칸을 채우는 masked language modeling은 양방향 문맥을 활용하는 별도의 학습 방식이다.
  • 문장 또는 토큰 시퀀스 전체의 결합 확률(joint probability)은 확률의 연쇄 법칙(chain rule)을 이용하여 각 토큰의 조건부 확률의 곱으로 분해할 수 있다.
  • 토큰 시퀀스를 x₁, x₂, …, xT라고 하면,
  • P(x₁, …, xT) = ∏t=1T P(xt | x1:t−1)
  • 여기서 오른쪽의 x1:t−1는 현재 토큰 xt보다 앞에 있는 모든 토큰을 의미한다. 첫 번째 토큰에는 이전 문맥이 없으므로 첫 번째 항은 P(x₁)이다.
  • 이를 전개하면,
  • P(x₁, …, xT) = P(x₁) × P(x₂ | x₁) × P(x₃ | x₁, x₂) × ⋯ × P(xT | x₁, …, xT−1)
  • 즉, 시퀀스 전체의 확률은 첫 번째 토큰의 확률과, 이후 각 토큰이 앞선 토큰들을 조건으로 등장할 확률을 모두 곱한 값이다.
  • Autoregressive language model은 이러한 조건부 확률을 순차적으로 모델링하여 다음 토큰을 예측한다.
Modeling a sequence of words
  • → 그냥 word classifier 문제로 볼 수 있음
  • softmax를 이용하여 다음 토큰 후보들에 대한 확률분포를 계산함.
  • Softmax 자체가 하나의 토큰을 고르는 것은 아니며, 실제 토큰 선택은 이 확률분포를 바탕으로 sampling하거나 argmax로 가장 확률이 높은 토큰을 선택하는 별도 단계에서 이루어짐.
  • 근데 단어가 너무 많음 (K=100,000)
  • 그래서 그냥, 단어 자체를 class로 두는 방법도 있음.
    → 훨씬 많이 예측해야 해서, 단어가 쌓일 수록 안 좋아질 수 있음.
  • ⇒ 단어 전체(word)와 문자(character) 사이의 단위인 subword token(예: BPE로 만든 토큰)을 예측 단위로 사용하는 방법이 있음.
  • 즉, byte 쌍 자체를 예측한다는 뜻이 아니라, BPE(Byte Pair Encoding) 등으로 구성한 subword 토큰 중 다음에 올 토큰을 예측하는 것.
